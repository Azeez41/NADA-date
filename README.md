# Pixel Date Quest

Create a Retro 8-Bit Interactive Dating Website

Create a fully interactive website that looks like a colorful 8-bit video game from the 90s.

DO NOT make it elegant, minimalist, realistic, glassmorphism, modern Apple style, or aesthetic Pinterest style.

The website should feel like someone is playing a goofy retro game.

Everything should be pixel art.

Use pixel fonts only (Press Start 2P or similar).

Use thick pixel borders.

Every animation should be choppy 8-bit style at around 8-12 FPS.

Color palette:

Hot Pink (#ff4fbf)

Purple (#8b4dff)

Lavender

White

Small accents of cyan and yellow

Background:

Animated checkerboard with slowly moving pixel clouds.

Tiny pixel stars twinkle.

Pixel cats randomly walk across the bottom of the screen.

Occasionally one pixel cat sits down and looks at the cursor.

Everything should have satisfying pixel sound effects.

No emojis anywhere.

No realistic graphics.

Everything must feel like a retro indie game.

Sound Design

Every transition uses 8-bit effects.

Victory music after Yes.

Retro menu sounds throughout.

Animations

Everything uses pixel-art animations.

No smooth easing.

Movement should feel like old console games.

Pixel confetti.

Pixel explosions.

Pixel smoke.

Pixel sparkles.

Pixel hearts made from square blocks.

Everything should feel handcrafted like a tiny retro game instead of a normal website.
